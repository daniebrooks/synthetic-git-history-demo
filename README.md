# Synthetic daily Git history demo

Generated on November 2, 2026. Every commit in this repository is synthetic.
Historical timestamps are deliberately assigned and do not represent work
performed on those dates or evidence of professional experience.

There is exactly one synthetic commit per calendar day, inclusively from
November 2, 2016 through November 2, 2026. There are no missing dates in the
repository history. Both author and committer timestamps use noon UTC.
Every commit message identifies itself as a synthetic demo.

`activity/date.txt` records the demonstration date for each revision.
Built using Git CLI fast-import in an isolated repository; existing projects
are untouched. No third-party generator or history-filtering dependency is needed.

Published at https://github.com/daniebrooks/synthetic-git-history-demo.
GitHub controls profile contribution rendering; repository history does not
guarantee how or when GitHub displays historical contribution years.
